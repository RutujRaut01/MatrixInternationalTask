# Matrix International Task

**Architecting the Neural Enterprise.**

A state-of-the-art AI consulting platform designed to showcase advanced intelligence solutions. Built with modern web technologies, this project features a high-performance, responsive interface with a premium glassmorphism aesthetic.

## Tech Stack

*   **Frontend:** React + Vite (Fast & Dynamic)
*   **Styling:** Custom Vanilla CSS (Glassmorphism & Gradients)
*   **Backend:** Node.js + Express (Robust API)
*   **Deployment:** Ready for Render/Vercel

## Features

*   **Immersive UI:** Smooth scrolling, micro-interactions, and responsive design.
*   **Contact Integration:** Functional backend API for client inquiries.
*   **Production Ready:** Optimized build process for seamless deployment.
